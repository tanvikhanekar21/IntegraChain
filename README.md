# Blockchain-Based Data Integrity and Document Verification System

A cybersecurity project developed using Python, FastAPI, SQLite, SHA-256 hashing, and a custom blockchain.

## Features

- Secure file upload
- SHA-256 hash generation
- SQLite database storage
- Custom blockchain implementation
- File integrity verification
- Tampering detection
- Blockchain validation
- Blockchain explorer
- QR code generation
- Professional responsive frontend

## Supported File Types

- PDF
- TXT
- JPG
- JPEG
- PNG

## Technology Stack

### Backend

- Python
- FastAPI
- Uvicorn
- SQLite
- SHA-256
- QR Code

### Frontend

- HTML
- CSS
- JavaScript
