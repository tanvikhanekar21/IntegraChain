How it works

Four steps from upload to proof.

  1. 01

    Upload document

    Choose a PDF, TXT, JPG, JPEG or PNG file up to 10 MB.

  2. 02

    Generate SHA-256 hash

    A unique fingerprint is calculated from the file's contents.

  3. 03

    Record integrity

    The fingerprint is stored in a block linked to the previous one.

  4. 04

    Upload the file again to see if it is original, tampered or not registered.
